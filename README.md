# TrucoHub
Sistema de cadastro de jogadores e gerenciamento de partidas de truco, com controle de pontuação, vitórias, histórico e dashboards.

# Tecnologias 
```
- Frontend: HTML(version 5)/CSS(version 3)/Javascript(version ES17)
- backend: NodeJS (v26.13.0)
- banco de dados: Firebase CLI (v15.35.0)   
- outras: ...
```
